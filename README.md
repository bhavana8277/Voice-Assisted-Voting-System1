# 🗳️ Voice-Assisted Voting System

A secure and accessible voting system designed for visually impaired users using voice guidance, face recognition, speech recognition, and encrypted offline vote storage.

## 🚀 Features

- 🎤 Voice-assisted voting
- 👤 Face recognition authentication
- 🗣️ Speech-to-text voting
- 🔒 Secure offline vote storage
- 🧑‍💼 Admin panel
- 📊 Vote counting module
- ♿ Accessible interface for visually impaired users

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/bhavana8277/Voice-Assisted-Voting-System1.git
cd Voice-Assisted-Voting-System1
```

## 2. Create a virtual environment

Windows

```bash
python -m venv .venv
```

Activate

```bash
.venv\Scripts\activate
```

Linux/macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

---

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run Backend

Go to backend folder

```bash
cd backend
```

Run the backend application

```bash
python app.py
```

> If your backend uses a different startup file (for example `main.py`) replace `app.py` with the correct filename.

---

## 5. Run Frontend

Open a new terminal.

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run

```bash
npm run dev
```
